# Support

Before asking for help:

1. Read the README, development guide, and open issues.
2. Run `amc doctor --json` when that command becomes available.
3. Reproduce with a synthetic or disposable machine when possible.
4. Remove credentials, private addresses, user data, screenshots, dumps, and transcripts.

Use GitHub Issues for reproducible bugs and feature requests. Use GitHub Discussions for usage
questions and design exploration once discussions are enabled. Report vulnerabilities only
through the private process in [SECURITY.md](SECURITY.md).

The project is community-supported. Public issue trackers are not suitable for urgent production
incident response.
